# Humanized Parent Style

Use this reference to reduce AI-like report prose while staying within assessment-report safety boundaries.

## Goal

The report should sound like a careful assessment teacher writing to real parents:

- concrete enough that parents can picture daily behavior
- warm but not sentimental
- professional but not textbook-like
- varied in rhythm without becoming literary
- faithful to the assessment data

## Safe Humanization Rules

1. Start from the child's actual score pattern, not from a general inspirational frame.
2. Prefer observable tendencies over abstract labels.
3. Vary sentence openings across dimensions; do not repeat "该维度反映...本次结果..." in every paragraph.
4. Replace abstract filler with specific scenes.
   - Weak: "这是一份宝贵的成长资源。"
   - Better: "在有材料可操作的任务里，孩子更容易进入状态。"
5. Reduce repeated template words when they appear too often:
   - 资源
   - 成长空间
   - 支持方向
   - 整体来看
   - 综合来看
   - 可以
   - 建议
   - 家长可以
   - 逐步
   - 安全感
   - 脚手架
6. Do not rely on soft metaphors such as "土壤", "小船", "路书", "画卷", "翅膀", unless the input or report style explicitly calls for it. One light metaphor is acceptable; repeated metaphors create AI flavor.
7. Use one concrete sentence before any summary sentence. Let the detail carry the warmth.
8. Advice should sound like something a parent can try this week, not like a counseling manual.
9. Parent wording must be natural and replaceable. It should not sound like a scripted performance.
10. Keep warmth in restraint: "先试一小步" is usually better than "共同托举孩子的未来".

## Forbidden Humanization Moves

Do not make the text more human by adding unsupported facts.

Avoid invented specifics such as:

- "上次你在班里..."
- "昨天老师说..."
- "你之前养过..."
- "你最引以为豪的一道数学题..."
- "你和同学发生..."

If a concrete example is useful, write it as a replaceable scene:

- "如果孩子最近提到某个自然现象，可以..."
- "可以选一个孩子熟悉的小作品..."
- "在一次普通作业后，家长可以..."

## Quick Revision Pass

Before returning, scan the report and revise if:

- two adjacent paragraphs start with the same sentence pattern
- a section contains more than two abstract summary terms
- parent wording assumes a past event not provided by the input
- a low-score dimension is described with shame, fear, or finality
- a high-score dimension is described as destiny, talent, or superiority
