# Final Report Patterns From Revised Expert Reports

This reference summarizes stable writing patterns distilled from revised expert reports.

Current corpus snapshot:

- 30 revised reports
- 4 overall guidance documents
- 120 section records
- 973 reusable segments
- sources: 陈专家版、潘专家版、汤专家版、综合版

The corpus should be used as RAG material, not pasted into the skill.

## Stable Macro Pattern

Final reports consistently follow this reader journey:

1. 前言: thank parents, state the report's purpose, and define it as a support reference.
2. 核心成长画像: first summarize strengths, then development space, and explain how they coexist.
3. 详细指标分析: define each dimension in plain language, then explain the child's score level.
4. 成长支持建议: give data-linked scenarios and actions.

## Core Growth Portrait Pattern

Good core portraits do not list every score. They select:

- 2-3 prominent strengths from high-score dimensions
- 1-2 developing areas from low-score or developing dimensions
- one connecting sentence explaining the mixed profile

Useful structure:

- "从整体画像看..."
- "比较突出的资源是..."
- "相对需要支持的是..."
- "这两部分并不矛盾..."

Avoid:

- turning the core portrait into a long dimension list
- using a single dramatic label to define the child
- describing normal-band dimensions as either major strengths or serious weaknesses

## Detailed Indicator Pattern

A strong indicator paragraph has three moves:

1. Dimension definition: "该维度反映..."
2. Level statement: "本次结果显示...处于优势区/常态区/潜力区..."
3. Parent-readable implication: "在日常学习中可能表现为..."

Keep level wording calibrated:

- 优势区: "较明显优势", "更容易投入", "具备较好基础"
- 常态区: "整体较稳定", "有一定基础", "仍可继续巩固"
- 潜力区: "仍在发展", "需要更多提示", "可以通过具体练习逐步提升"

## Growth Support Pattern

A useful suggestion has:

- data basis: which strength or developing area it supports
- scene: homework, reading, exploration, expression, parent-child communication
- adult action: what parent/teacher does
- adult wording: one sentence they can say
- first step: something small enough to try today

Good suggestions often use strengths as scaffolds:

- use design/building interest to support flexible thinking
- use learning meaning or school belonging to support persistence
- use curiosity to support deeper questioning
- use stable emotional resources to support expression practice

## Corpus Caution

The revised corpus is high-value but not perfect. Some completed reports still contain occasional inflated words such as "极其", "完美", "第一梯队", or "绝不".

When a RAG segment conflicts with current safety, score-band, or style rules, follow the skill rules and rewrite the expression more moderately.
