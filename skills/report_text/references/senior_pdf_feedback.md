# Senior Review Feedback: Writing And Report Structure

This reference distills the senior review of the first PDF prototype. It is a binding quality guide for future TextAgent, CheckerAgent, and renderer work.

## Professional Foundation Without Academic Jargon

Each important indicator needs two linked moves:

1. **Professional definition:** use one or two short, accurate sentences to explain what the indicator observes in educational, developmental, or social-interaction terms.
2. **Parent translation:** immediately explain what the current result may look like in ordinary situations, using only the supplied assessment evidence.

The report must be professional but easy for elementary-school parents to read. Do not write like a research paper. Do not use pseudo-professional claims such as "打通神经回路", and do not replace plain explanation with jargon such as "元认知监控" unless it is briefly explained in ordinary language and truly needed.

## Do Not Explain A Single Score As Personality

A one-time assessment result cannot establish a fixed personality explanation.

- Avoid: “这反映的是性格里的谨慎。”
- Prefer: “这提示孩子现阶段在群体互动中更倾向于先观察、准备后再参与。”
- Prefer: “这可能是一种当前的行为策略或反应风格，不等于固定性格或能力不足。”

Never use a single indicator to infer permanent personality, motivation, family causes, or developmental history.

## Whole-Profile Visualization

The opening overview must include **all dimensions supplied for this assessment**, not only selected high or low scores. It should let parents see the full profile before reading detailed interpretation.

If many dimensions are supplied, use a grouped or multi-panel overview in one visual block. Do not silently truncate the score list. The overview should preserve each input score's own level and interpretation.

## No Cross-Construct Averages

Do not calculate or display a “module average” by averaging different psychological constructs. These scores are separate norm-referenced results, not additive components of one common score.

Module pages should show the complete distribution of the supplied indicators in that module, their individual positions, and their relationship to the module theme. Do not invent a total score without an explicit scoring-service field.

## Organize Suggestions By Education Scene

Growth support should not read like an unstructured action list. Classify each suggestion under one of these parent-facing categories:

1. 学习与日常
2. 课外与探索
3. 亲子互动与沟通

Each card still needs data basis, action, natural parent wording, and a small first step. When there are at least three suggestions, cover all three categories unless the input makes one category clearly irrelevant; document that exception in `risk_flags`.
