# Section Structure

## Recommended Report Sections

### 1. Preface

Purpose: establish a respectful, professional first impression for parents.

Include:

- thanks for trust and participation
- explain that the report is a reference for understanding and supporting the child
- name the three main sections: 核心成长画像、详细指标分析、成长支持建议
- remind adults that daily observation and interaction are still important

Avoid:

- long emotional opening
- medical or diagnostic framing
- claiming the report can fully define the child

Suggested length: 100-180 Chinese characters.

### 2. Core Growth Portrait

Purpose: give parents a concise, faithful portrait.

Include:

- two main strengths from high dimensions
- one developing area from low or developing dimensions
- one sentence explaining how these traits can coexist

Avoid:

- middle-level dimensions unless needed for balance
- dramatic labels
- unsupported life details

Recommended title: 核心成长画像.

Organize as:

- 【优势】: 1-3 data-supported strengths.
- 【潜力】: 1-2 development areas that need support.

Each item may include:

- 指标依据: which dimensions support the point and what they measure.
- 评估结果: what the result suggests, calibrated to the score band.

### 3. Detailed Indicator Analysis

Purpose: explain what each important score means.

For every supplied dimension (not only key dimensions):

- begin with one short, accurate professional definition of what the indicator observes
- immediately translate that definition into parent-readable daily behavior
- state the child's current tendency
- connect it to observable parent-friendly behavior
- state or imply the level band: 优势区、常态区、潜力区
- avoid repeating the numeric score unless useful
- do not use a single score to explain fixed personality, family cause, or long-term development. Prefer “现阶段在群体互动中的行为策略/反应风格” to “性格里的谨慎”。

Use one clearly separable heading per indicator: `【输入中的指标名】`.

Required two-layer sentence pattern:

1. `【注意稳定性】抗干扰与持续聚焦：` followed by one concise sentence explaining what the indicator observes.
2. `本次结果提示……` followed by a plain-language description of the child's current tendency in a replaceable learning or daily-life situation.

Use `expert_definition_method.md` for the construct definition and parent-translation method. `indicator_definition_catalog.json` is a terminology reference, not a script to copy. The translation must not invent an actual classroom or family event. A mild image can make the sentence natural, but it cannot replace the definition or exaggerate the evidence.

Recommended title: 详细指标分析. Avoid using “评价” in section titles.

### 4. Strength-Development Relationship

Purpose: help parents understand mixed profiles.

Use when the child has both clear strengths and clear developing areas.

Example logic:

- strong logical reasoning + cautious open-ended thinking
- rich ideas + slower convergence
- strong self-perceived emotion regulation + still needs support in flexible problem solving

### 5. Growth Support Suggestions

Purpose: give parents next actions.

Recommended title: 成长支持建议.

Start with one overall suggestion paragraph:

- summarize the child's main strengths
- summarize the most important developing area
- explain the support direction in one or two sentences

Then give detailed suggestions. Each suggestion must include:

- category selected by school stage
- scene
- why this scene matches the data
- reader-owned action
- support wording
- small first step

Example:

"场景：作业与学习。孩子在规则清楚的任务中更容易发挥，但遇到开放题时可能需要时间转换思路。今晚做完一道题后，家长可以问：'你刚才用了这个办法，如果换一个角度，还能不能试第二种？' 先不评价对错，只记录想法数量。"

Good suggestion patterns from expert review:

- For attention drift: split work into 5-10 minute segments, use a timer or hourglass, then allow 1-2 minutes of movement.
- For low question curiosity: after a homework or experiment result, ask "你觉得它为什么会这样？还有没有别的可能？"
- For cautious open-ended thinking: use a low-pressure "two more ideas" game and avoid judging correctness too early.
- For expression anxiety: start with private family sharing before public presentation.
- For many ideas but weak convergence: use a mind map to group ideas, then choose one main line.

Suggested domains:

- elementary: 学习与日常、课外与探索、亲子互动与沟通
- junior high: 自我成长与学习规划、兴趣探索与项目实践、生涯启发与发展规划

For junior high, title the visible section `成长支持与生涯规划建议`.
The first category turns the profile into a study/self-management experiment;
the second uses questions and projects to test sustained interests; the third
offers one or two evidence-linked direction hypotheses and a concrete
validation activity. Do not infer a suitable major or occupation from scores.
Parents and teachers remain support resources inside the cards rather than a
separate category.

### 6. Boundary Note

Purpose: explain report limits without alarming parents.

Keep it brief:

"本报告基于本次评估结果生成，用于帮助家长理解孩子当前的学习与发展特点，不能替代专业诊断或个别化咨询。如家长发现相关状态持续影响学习、生活或亲子关系，建议结合日常观察进一步寻求专业支持。"

## Page-Level Text Limits

For PDF layout:

- core portrait block: 120-220 Chinese characters
- dimension block: 80-160 Chinese characters; a complete report must contain one block for every supplied metric
- suggestion block: 120-220 Chinese characters
- boundary note: 60-120 Chinese characters

Prefer short paragraphs. Avoid dense walls of text.
