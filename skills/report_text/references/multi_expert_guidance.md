# Multi Expert Guidance

This file consolidates the four overall guidance documents from Pan, Tang, Chen, and the integrated revised set.

## Shared Success Criteria

A good report should let parents finish with three clear feelings:

- "This sounds like my child."
- "I understand what the result means."
- "I know what I can do next."

## Shared Hard Standards

1. Data portrait and prose must match.
   - Strengths in the portrait must come from high-score or high-level dimensions.
   - Developing areas must come from lower-score, lower-level, or developing dimensions.
   - The core portrait and detailed indicator analysis must not contradict each other.
2. Score level must be explicit and calibrated.
   - Parents want to know whether each indicator is in an advantage, normal, or developing range.
   - The same level should receive the same strength of wording across the report.
3. Language must be warm, respectful, and non-frightening.
   - Low scores should be written as developmental information.
   - Do not make parents or children feel blamed.
4. Suggestions must be concrete and simple.
   - Base suggestions on the child's strengths and developing areas.
   - Organize suggestions by learning, daily life, thinking, social, or parent-child scenes when useful.
   - Include an action and a small first step.

## Visible Wording

Avoid visible terms that may create unnecessary anxiety for parents:

- "心理测评"
- "心理诊断"
- "临床判断"

Prefer neutral wording:

- "本次评估"
- "综合素质评估"
- "发展观察"
- "本次结果"

The safety note may mention that the report cannot replace professional diagnosis or consultation, but the main report should not frame the child as being psychologically examined.

## Dimension Explanation Pattern

Use "professional definition + daily-life translation":

1. Briefly define what the indicator measures.
2. Immediately translate it into parent-readable daily behavior.
3. Then explain the current child's result and level.

Avoid using the same sentence frame in every dimension. Do not start every paragraph with "该维度反映...".

Good rhythm:

- "问题好奇心主要看孩子是否愿意继续追问原因。放到日常里，就是遇到一个现象时，会不会多问一句'为什么'。本次结果..."
- "注意稳定性关注的是孩子能否在目标清楚的任务中维持投入。对这个年龄段的孩子来说，它常体现在作业、阅读或拼搭任务中..."

## Data Sketch Rule

Before writing, build a data sketch:

- top 30% or advantage dimensions
- bottom 30% or developing dimensions
- middle dimensions
- mixed profiles that need transition explanations

The core portrait should usually focus on advantage and developing dimensions. Middle dimensions are used for balance, not for dramatic conclusions. If a child is mostly middle-range, write a balanced portrait instead of forcing a strength/weakness storyline.

## Low-Score Rule

Use a three-layer explanation:

1. Normalize: many children at this stage may show this tendency.
2. Specific tendency: describe what the data currently suggests.
3. Path forward: give one small way adults can support the child.

Do not write low-score areas as defects, moral problems, or fixed traits.
