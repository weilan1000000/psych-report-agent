# Expert Writing Core

This reference is distilled from the four overall guidance documents, Pan and
Tang teacher review summaries, and the revised report corpus. Apply it before
using any Excel score-band reference or report exemplar.

## The Parent Test

A parent should finish the report with three answers:

1. What does this current result mean for my child?
2. What can I notice without treating the report as a label?
3. What can I try this week?

Do not use a score comment merely to sound professional. Every paragraph must
earn its place by answering one of these questions.

## Evidence Ladder

Keep these evidence types separate:

1. **Measured conclusion**: score, supplied level, direction, and input
   interpretation. State this accurately.
2. **Developmental meaning**: what the construct observes. Use a precise,
   parent-readable definition.
3. **Conditional observation**: an optional scene for a parent to notice.
   Write "在……情境中，家长可留意……" or "当任务需要……时，孩子可能……".
4. **Support action**: a small, replaceable action. Never present it as a
   historical fact about the child.

Never jump from level 1 to a claimed real-world event, school relationship,
habit, motivation, personality, or family cause.

## Indicator Paragraph Method

Each indicator needs an individual rhetorical purpose, not a fixed sentence
template. Select one of these entry patterns and rotate them across a report:

- **Construct-first**: name the process, then explain the current result.
- **Task-first**: describe the type of task the construct concerns, then name it.
- **Result-first**: state the supplied level once, then explain what the
  construct means.
- **Contrast-first**: for a balanced profile, clarify what the result does and
  does not mean before offering a parent observation.

The completed paragraph still contains the same four evidence layers, but it
must not repeatedly begin with "本次结果显示", "从本次结果看", or "该指标".

## Profile Method

The core portrait is an argument, not a score list.

- Select at most three representative strengths.
- Include a support priority only when the input actually marks it as a
  potential/developing area.
- Use normal-range dimensions to explain balance or a meaningful tension, never
  rename them as a potential area.
- Explain mixed patterns when data supports them, such as high interest with
  ordinary follow-up questioning. Do not force one global personality label.

## Level Calibration

- **Advantage**: name a clear current resource, then say how it may be used or
  protected. Avoid destiny, superiority, or certainty.
- **Normal**: describe a stable current foundation. Do not convert it into a
  hidden weakness or a disguised advantage.
- **Potential/developing**: normalize the developmental task, give a cautious
  current tendency, then offer one small support path.

The supplied level is authoritative, including score-direction exceptions and
expert-chart overrides. Raw score alone never changes a level.

## Parent-Facing Voice

- Prefer one concrete, conditional observation before a summary sentence.
- Use professional terms only when the following phrase translates them.
- Use short, calm sentences rather than praise-heavy or academic language.
- Avoid absolute, diagnostic, personality-label, and blame language.
- Limit repeated stock phrases. A report with many indicators needs varied
  openings, connectors, and sentence lengths.

## Suggestions

Build a suggestion from a data relationship, not a generic activity library:

`strength or current resource -> support target -> scene -> action -> parent wording -> first step`

Cover learning and daily life, extracurricular exploration, and parent-child
communication when all three are applicable. Suggestions must be feasible for
an elementary-school family this week.

## Corpus Boundary

The revised expert reports are evidence of writing methods, not a fact source
for a new child. Some historical paragraphs contain exaggerated, outdated, or
over-specific wording. Preserve the method; do not preserve their claims.
