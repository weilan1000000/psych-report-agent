# 报告生成技能

目标：根据结构化心理测评结果生成自然、温和、专业、可读性强的中文报告。

必须做到：
- 先理解输入中的量表名称、用户场景、分数、等级和维度解释。
- 报告必须忠实于输入，不补充用户没有提供的经历、身份、病史或事件。
- 每个重要维度都要有对应解释，不能只写总体感受。
- 把分数翻译成用户能理解的状态描述，而不是机械复述数字。
- 建议要具体到行为，例如时间、场景、做法或可观察动作。
- 语气要像专业人员写给真实用户，既不冷冰冰，也不过度亲密。

避免：
- “首先、其次、最后、综上所述”等模板化连接。
- “保持积极心态”“多休息”这类空泛建议。
- 过度文学化的比喻。
- 诊断化、标签化、吓人的表达。
