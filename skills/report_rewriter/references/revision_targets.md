# Revision Targets

## Score-Band Mismatch

Problem:

- 潜力区 written as advantage
- 常态区 written as exceptional or poor
- 优势区 written as only average

Instruction pattern:

"Rewrite the paragraph about [dimension]. Keep the data basis, but change the tone to [优势区/常态区/潜力区] wording. Replace inflated or negative phrasing with developmental language."

## Missing Structure

Problem:

- missing 前言
- missing 核心成长画像
- missing 详细指标分析
- missing 成长支持建议
- missing 报告说明

Instruction pattern:

"Add [section]. Use parent/teacher-facing wording. Keep it brief and make clear this report is a support reference, not a diagnosis."

## Unsupported Claim

Problem:

- invented family, school, peer, or motive details

Instruction pattern:

"Delete the unsupported claim. Replace it with a cautious statement based only on the score, level, interpretation, or explicit input background."

## Weak Advice

Problem:

- advice not linked to data
- advice too abstract

Instruction pattern:

"For each suggestion, state the data basis, scene, adult action, adult wording, and first step. Use current strengths as scaffolds for developing areas."

## Style Issue

Problem:

- jargon
- inflated wording
- mechanical AI wording

Instruction pattern:

"Simplify the wording for parents/teachers. Remove exaggerated terms and replace them with calibrated, observable descriptions."
