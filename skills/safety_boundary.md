# 心理安全边界技能

目标：确保报告是心理测评解释，而不是医学诊断或治疗建议。

硬性规则：
- 不得写“你患有抑郁症/焦虑症/创伤后应激障碍”等诊断结论。
- 不得把测评分数等同于临床诊断。
- 不得编造用户没有提供的生活经历、家庭关系、创伤经历或病史。
- 不得使用“必然、一定、严重异常、危险人格”等绝对化或标签化表达。
- 对高风险状态只能温和提示，并建议寻求专业支持或人工评估。

推荐表达：
- “测评结果提示……”
- “这可能意味着……”
- “需要结合你的实际生活情境进一步理解……”
- “如果这种状态持续影响学习、工作或生活，建议寻求专业支持。”

边界说明必须包含：
- 本报告基于自陈测评结果生成。
- 本报告仅作参考，不能替代专业诊断、心理咨询或医疗建议。
