# 图表设计技能

目标：为测评报告选择和描述适合排版的图表，而不是随意堆砌图形。

图表选择：
- 雷达图：适合总览多个维度。
- 横向柱状图：适合比较同一维度下的多个子项。
- 仪表盘：适合展示单个综合指数。
- 环形进度图：适合展示单个得分等级。

心理/教育评估报告图表策略：
- 总体画像优先使用 profile 折线图或横向总览图，适合展示多个指标的高低起伏、优势区/常态区/潜力区位置。
- 详细指标分析优先使用按模块分组的横向柱状图或线性仪表盘，家长最容易读懂分数长短和水平区间。
- 成长建议页只使用小型支持重点图，不要放复杂大图；图表只负责说明“为什么建议这些方向”。
- 附录或专家复核页可以使用完整分数表、profile 图和更密集的指标信息。
- 雷达图只适合 5-7 个大领域的总览，不适合直接放 15-20 个原始指标；轴太多会让家长误读形状面积。
- 环形图、圆形仪表盘只适合单个总分或单个指数，不适合多个维度比较。
- 表格适合追溯分数，不适合作为家长主阅读页面的核心视觉。

推荐决策表：
- overview / 核心画像：profile 折线图 + 区间背景，或 5-7 个领域卡片。
- domain_detail / 模块解读：模块仪表盘 + 横向条形图。
- support_focus / 支持重点：小型条形图或 2-4 个数据徽章。
- appendix / 分数依据：完整表格 + 必要的 profile 图。

图表设计原则：
- 图表标题必须清楚说明图表含义。
- 图表配色要服从报告主题色，不要每页随机配色。
- 图表标签要足够大，PDF 打印后仍可读。
- 图表下方必须有文字解释，避免只展示数字。
- 不要使用过多网格线、阴影和装饰。
- 不要把颜色作为唯一信息编码；同时保留分数、水平标签或参考线。
- 参考线必须稳定，例如 55/70 或项目定义的潜力区/常态区/优势区，不要每页随意改变。
- 发展中或低分区域使用暖黄/橙色即可，避免大面积红色或警报感。
- 优先使用长度和位置表达大小差异，少用面积、角度或 3D 效果。
- 每张图至少给出一个可读结论，例如“该模块均值处于常态区，支持重点集中在表达启动”。
- 如果图表服务专家复核，可以更密集；如果服务家长阅读，必须降低信息密度并加解释。

原始分与常模图表硬规则（2026-07-09）：
- 当输入 `scale_config.classification_basis` 为 `fixed_norm_20_80_raw_score` 时，图表坐标必须使用 `students_scores` 第一张分数表中的原始分，不得转换为百分制、班级排名或同伴百分位后再绘图。
- 详细指标图使用固定常模 P20/P80：原始分 <= P20 为潜力区，P20 < 原始分 < P80 为常态区，原始分 >= P80 为优势区。
- 模块页每个指标使用一条横向三段色带：蓝色潜力区、绿色常态区、橙色优势区；学生原始分用箭头标在色带上。
- 箭头和主图中不直接显示具体原始分数；数值只放在附录或结构化数据中，主报告让家长看“落在哪个区域”。
- 此规则下不得在图中写“班级前 20%/后 20%”“超过多少同学”作为区域依据，除非附录另行说明那只是复核信息。

当前 MVP：
- 使用横向柱状图。
- 重点项用黄色强调，一般项用绿色。
- 班级均值或参考值使用浅绿色。

当前推荐图表组合：
- 第一页：专家控制板式 profile 折线图，展示整体画像。
- 模块页：家长仪表盘式横向条形图，展示该模块内指标。
- 建议页：支持重点小仪表盘或数据徽章。
- 最后一页：完整分数表，便于复核但不抢占主叙事。
