# PDF 视觉风格指南

目标：让 PDF 报告具有稳定的产品感，而不是像临时拼接的图文。

参考方向：
- 《高阶思维》样例：黄色/绿色主题、底部色带、上图下文、一页一主题。
- 《GPI》样例：页眉清晰、图表与说明成组、页脚稳定、留白充足。
- 公开心理/教育评估样例：常用 score profile、分数表、解释段落和建议模块；主报告应吸收其专业感，但避免过度临床化。
- 数据可视化通用原则：面向读者选择图表，减少认知负担，使用清晰标题、注释、参考线和一致色彩。

设计 token：
- 页面：A4 纵向。
- 主色：蓝绿或青绿，用于页眉、标题、主要图表数据和专业感。
- 辅色：绿色，用于优势、成长资源和积极提示。
- 强调色：暖黄/橙色，用于潜力区、支持重点和需要家长关注的项目。
- 正文：深灰或近黑，避免纯黑大面积压迫。
- 边距：顶部留白较大，左右留白稳定。
- 背景：以白色或极浅灰绿为主，不使用大面积高饱和渐变。
- 字体：Microsoft YaHei / PingFang SC / Noto Sans SC fallback；正文等效 12-14px，图表标签不低于 10px。
- 圆角：卡片和图表容器 6-8px，避免过度可爱化。
- 页眉页脚：每页稳定显示报告类别、主题标签、年级/对象信息和页码。

家长版视觉语气：
- 专业但不冰冷，温和但不幼稚。
- 不使用医学红、警报图标、病理化标签或临床诊断风格标题。
- 不把孩子“低分”放成醒目的惩罚色块；应呈现为“支持重点”或“潜力区”。
- 图表下方必须有一句普通家长能理解的解释。
- 建议卡片要比正文更容易扫读，突出场景、家长动作和第一步。
- 首页的总览图必须覆盖本次输入的全部已测指标，并固定为一张连续折线/profile 图；指标多时缩紧纵向标签、使用领域分色和底部领域色带，不得拆成多个仅含少量标签的小图，也不能静默截断为少数指标。
- 不计算或展示跨心理建构的“模块均值”。模块页应呈现该模块全部已测指标的分布和各自位置；只有评分服务明确提供模块总分时才能展示总分。
- 成长建议按“学习与日常、课外与探索、亲子互动与沟通”组织，避免流水账式罗列。
- 可见页眉、标题、PDF 元数据不得出现样本文件名、内部主题名（例如“专家控制板 × 家长仪表盘”）、prompt 或调试信息。没有脱敏显示名时，使用年级/年龄段和“儿童成长发展报告”作为占位。
- 图表中的“优势区/常态区/潜力区”与 55/70 等参考线只能来自本次量表版本提供的层级规则；不能由 renderer 用全局分数阈值猜测。没有规则时，展示分数位置并说明“以本次测评提供的层级与说明为准”。
- 若量表版本声明 `fixed_norm_20_80_raw_score`，所有主报告图表使用原始分定位，并以固定常模 P20/P80 划分蓝色潜力区、绿色常态区、橙色优势区；图中只显示箭头位置和区域标签，不直接显示具体原始分。
- `fixed_norm_20_80_raw_score` 模式下，禁止把柱长画成 0-100 百分制得分，也禁止把班级排名/同伴百分位作为主图区域划分依据。
- TextAgent 生成的前言、核心画像、指标解读、成长建议、报告说明，必须被 PDF 显式呈现，或在渲染契约中说明其被合并到哪个页面。

推荐页面视觉节奏：
- 封面/总览：大标题 + profile 折线图 + 核心画像。
- 模块页：标题 + 模块仪表盘 + 2-4 个指标解释块。
- 建议页：支持重点小图 + 1-2 条建议卡片。
- 附录页：表格 + 边界说明。

低质量风险：
- 图表和文字没有对应关系。
- 首页总览遗漏已测指标，或用不同心理指标的简单平均数冒充模块表现。
- 一页塞太多模块。
- 标题层级混乱。
- 页面底部大量空白但内容挤在上方。
- 图表过小、标签不可读。
- 图表标签或附录把输入“较高”改写成“优势区”等层级误标。
- 颜色过多且没有统一主题。
- 所有页面都像表格或仪表盘，没有专家式解释。
- 所有页面都像文章，没有先图后文的可视化入口。
- 只展示分数，不告诉家长“这意味着什么”和“可以怎么做”。
- 使用夸张装饰、过多卡片嵌套、阴影和复杂背景，削弱专业感。

当前项目定稿候选：
- 优先使用“专家控制板 × 家长仪表盘”风格。
- 总体画像继承专家报告的 profile 折线图专业感。
- 详细指标继承家长仪表盘的清晰条形图。
- 建议页使用简洁卡片，把 TextAgent 的场景化建议转为可执行版面。

渲染后核验：
- 每次 PDF 生成都保存全部 `.page` 的逐页截图，截图数量必须等于 HTML 的页面数量。
- 人工抽检首页、至少一页模块页、至少一页建议页和附录页；确认无溢出、遮挡、过小文字、内部标识或层级误标。
