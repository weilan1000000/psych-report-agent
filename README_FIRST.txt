PSYCH REPORT AGENT - READ THIS FIRST
===================================

1. Do NOT double-click SETUP_FIRST_TIME.cmd inside the ZIP preview window.
   Chinese: 不要在 ZIP 压缩包预览窗口中直接运行安装按钮。
2. Right-click the ZIP file and choose "Extract All".
   Chinese: 右键压缩包，选择“全部解压”。
3. Move/open the extracted folder in a normal writable location, for example:
   D:\PsychReportAgent
   Prefer an empty folder. If an older copy exists, delete its .venv folder or
   let SETUP_FIRST_TIME.cmd repair it automatically.
4. Open that extracted folder and double-click SETUP_FIRST_TIME.cmd.
5. Keep the internet connected while Python, Node.js, dependencies, and Chromium
   are checked or installed.
6. When setup reports success, press any key once more to open the report console.

After setup, use the desktop shortcut named "Psych Report Console".

JSON input example: templates\assessment_input_example_26_metrics.json
Chinese instructions: templates\README.md
Full system manual: docs\SYSTEM_MANUAL.md

If setup fails, send the file output\setup\setup.log to the project maintainer.
