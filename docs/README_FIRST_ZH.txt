心理报告 Agent：首次使用说明
=============================

重要：不要在 ZIP 压缩包预览窗口中直接双击任何 CMD 文件。

正确步骤：

1. 右键收到的 ZIP 压缩包，选择“全部解压”。
2. 将完整文件夹解压到普通、可写的位置，例如 D:\PsychReportAgent。建议使用空文件夹；
   如果覆盖了旧版本，安装器会自动检查并重建不属于当前电脑的 .venv。
3. 打开解压后的文件夹，确认能看到 scripts、report_app 等子文件夹。
4. 双击 SETUP_FIRST_TIME.cmd，保持网络连接，等待依赖检查和安装完成。
5. 看到安装成功后，按任意键会直接打开报告控制台。
6. 以后也可以从桌面打开 Psych Report Console。

生成结果说明：

- “已通过”：仍需抽查被试姓名、分数、等级和 PDF 排版，再正式发送。
- “待复核”：先点击“复核说明”，查看还剩哪些问题、为什么需要人工介入以及处理顺序。
  审核稿不能直接发送给家长或学生。
- “原始检查 JSON”：供开发人员排查规则和模型输出，普通使用者优先看“复核说明”。

如果安装失败，请把 output\setup\setup.log 发给项目维护人员。
