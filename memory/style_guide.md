# 报告风格记忆

当前阶段的目标风格：
- 专业、温和、克制。
- 像测评师写给真实用户的说明，而不是客服回复。
- 让家长/老师感到被尊重，并知道报告只是支持理解孩子的参考。
- 不过度文学化，不使用夸张比喻。
- 不机械罗列分数，要解释分数背后的状态含义。
- 段落可以有标题，但不要使用“好的，下面是……”这种聊天开场。

低 AI 味规则：
- 少用“首先、其次、最后、综上所述”。
- 少用“保持积极心态”“学会放松”等空泛表达。
- 避免每段都用同一种句式开头。
- 建议尽量落到具体生活动作。
- 不要为了显得温暖而过度煽情。
- 每个已测指标都先用一两句给出准确的教育/发展性专业界定，再立刻翻译成家长能理解的当前倾向；每项都要有独立的【指标名】解读块。不要只说大白话，也不要写成论文。
- 不把单项分数写成“性格里的谨慎”“固定人格”等结论；使用“现阶段的行为策略、反应风格、互动倾向”等可变化表达。
- 成长建议按学段组织：小学使用“学习与日常、课外与探索、亲子互动与沟通”；初中使用“自我成长与学习规划、兴趣探索与项目实践、生涯启发与发展规划”，避免跨学段混用。
- 不使用“评价”作为主要章节名，优先用“分析”“成长支持”等更少评判感的表达。
