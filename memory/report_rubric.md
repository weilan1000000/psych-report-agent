# 报告质量评分记忆

合格报告建议阈值：
- 85 分以上：可以进入人工抽检或交付候选。
- 75-84 分：需要重写一次或由 TextAgent 按 CheckerAgent 指令二次改写。
- 75 分以下：需要回到 prompt、输入信息或量表解释层面排查。

质量优先级：
1. 安全和专业边界高于文采。
2. 忠实于测评结果高于个性化发挥。
3. 分数层级校准高于好听表达：优势区、常态区、潜力区的文字强度必须匹配。
4. 具体建议高于泛泛安慰。
5. 自然表达高于复杂术语。

人工审核时重点看：
- 是否有无依据判断。
- 是否有诊断化表达。
- 是否遗漏关键高分维度。
- 是否把常态区写成优势或问题，是否把潜力区写得过高。
- 是否缺少前言、核心成长画像、详细指标分析、成长支持建议或报告说明。
- 建议是否真正能做。
- 建议是否能看出来自哪些优势和不足。
- 是否像模板拼接。
