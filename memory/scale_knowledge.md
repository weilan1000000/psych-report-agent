# 儿童创新潜能与综合素质量表解释记忆

当前报告的数据源来自 `students_scores_original.xlsx` 的第一页 `分数明细表`。完整指标目录见 `config/scale_catalogs/students_scores_100.json`。每一份测评只会传入其中的部分指标；未传入不代表低分、常态或没有该能力。

## 图表分数硬规则（2026-07-09 更新）

1. 以后的报告图表一律使用 `students_scores` 第一张分数表中的原始分数作图，不再把原始分转换为百分制后绘图。
2. 详细指标图采用 `初中生_常模分界值_20_80.xlsx` 的固定常模 P20/P80 分界值：原始分 ≤ P20 为潜力区，P20 < 原始分 < P80 为常态区，原始分 ≥ P80 为优势区。
3. 每个详细指标图使用横向三段色带：左侧蓝色为潜力区，中间绿色为常态区，右侧橙色为优势区；学生原始分用箭头标出位置。
4. 图中不直接标注具体原始分数；具体分数可放在附录或结构化 JSON 中，正文图表只展示位置与区间。
5. 常模分界值是固定值，不随班级、学校或当前样本变化。班级排名/同伴百分位不能再作为图表绘制坐标。

## 输入解释优先级（硬规则）

1. 上游评分服务提供的 `level`、`percentile_band`、`interpretation`、`direction` 是唯一的层级与方向来源。
2. 不能用全局分数阈值把“较高”“top_30”自动改成“优势区”，也不能把“中等偏低”自动改成“潜力区”。可见报告必须沿用或谨慎转述上游层级。
3. 若只有 `score` 而没有本量表版本的层级规则，不能在正文、图表、data_sketch 中断言“优势区/常态区/潜力区”。在 `risk_flags` 标记“缺少层级或方向规则”，并只写“本次分数为 X，需结合量表解释判断”。
4. 不从指标名称推断方向。尤其是“负性情绪”、抑制控制(Nogo)、抑制控制(go)及任务型指标，必须依赖输入提供的 `direction` 或 `interpretation`。
5. 当 `scale_config.classification_basis` 为 `class_rank_percentile` 时，默认按同班同伴排名计算：`rank_percentile <= 20` 为潜力区，`20 < rank_percentile <= 80` 为常态区，`rank_percentile > 80` 为优势区。若输入同时提供 `extreme_score_overrides`，先执行方向一致的满分/有利方向最低分硬覆盖；其余指标再按同伴排名评级。原始 `score` 不可自行替代上游规则，但可用于检索评分服务提供的分数段写作模板。
5. `data_sketch` 中每个维度的 `source_level` 必须逐字保留输入的 `level`；可见 `level` 只能使用相同或更中性的表述，不能加强为更高或更低的区间。
6. 对 `lower_is_better` 指标，`direction` 只说明有利方向；最终文字结论仍以输入 `level` 为准。若输入是潜力区，不得因为原始 score 较低而写成“负担较低”或“较少受困扰”。
7. 当输入 `rating_basis` 为 `expert_report_gold_reference` 时，专家原报告图表的 `level` 优先于本地对 Excel 原始分数的重算。此规则只用于已核验的金标样本；正式 API 应由上游评分服务提供最终 `level`。

## 维度分组

创新行为倾向：
- 表演、文学、设计、科学、社会。
- 用于描述孩子更偏好通过哪类活动表达创造力或探索兴趣。
- 不要把单一偏好写成能力诊断，例如“只适合走理工路线”。

好奇心：
- 兴趣好奇心、问题好奇心。
- 兴趣好奇心偏向是否容易被新活动、新材料吸引。
- 问题好奇心偏向是否主动追问原因、机制和更多可能性。
- 高兴趣、低追问不是矛盾，要解释为“喜欢投入，但深层追问还需要成人带一带”。

创新思维：
- 思维流畅性、思维灵活性、思维独创性、思维聚合性。
- 流畅性更偏向想法数量。
- 灵活性更偏向转换角度。
- 独创性更偏向想法的新颖程度。
- 聚合性更偏向从多个想法中收束、筛选和形成主线。
- 不要把一个思维维度的高分套用到所有思维维度。

认知与执行功能：
- 认知灵活性、规则抽象能力、学习速度、注意稳定性、整体执行功能、抑制控制(Nogo)、抑制控制(go)、逻辑推理。
- 这些维度涉及任务中的认知表现，不能扩大成日常所有场景中的固定人格。
- “抑制控制(Nogo)”和“抑制控制(go)”必须按输入定义解释，不凭名称推断。

学业幸福感与情绪：
- 学习乐趣、学校归属感、学习意义感、学习自信感、积极情绪、负性情绪、情感平衡。
- 这些更接近孩子在学习和学校生活中的主观感受或情绪状态。
- 如果来自自评，要写成“从自评结果看”“孩子对自己的感受显示”，不能写成客观事实。

## 层级写作规则

默认使用三类层级：
- 优势区：明显优势，但用克制语言。
- 常态区：稳定、普通、具备基础，不夸大、不贬低。
- 潜力区：正在发展、可通过支持提升，不贴负面标签。

如果输入只提供分数而没有层级：
- 只能按该量表版本随 API 一并传入的评分规则换算。
- 如果没有评分规则，TextAgent 应在 `risk_flags` 中标记“缺少层级规则”，并用谨慎表达，不直接断言“优势区/潜力区”。

## 安全边界

- 不做医学诊断。
- 不说孩子“患有”“存在某种障碍”。
- 不编造家庭经历、学校经历或具体行为。
- 不把一次测评分数写成永久能力或人格。
